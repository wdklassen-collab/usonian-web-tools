This repository contains earlier browser-based guitar-building and CNC tools and is retained as a legacy/reference codebase.

## Legacy Tools

- **Fretboard Generator v4.1.0** — custom fretboard layout with saved designs and Easel-compatible SVG exports.
- **Radius Dish Creator v0.2.2** — 3D preview plus STL and Easel-compatible G-code exports.
- **Neck Template Generator v1.1.9** — bolt-on neck side-profile layout with automatic inch/mm field conversion, fractional-inch entry, a three-point draggable transition editor, transition-focused zoom, SVG export, and portrait tiled 1:1 printing.

## Important

The production versions of Usonian web tools now live in the `wdklassen-collab/usonian-guitar-company` repository alongside the main Usonian Guitar Co. website. This repository should not be used as a deployment source.
