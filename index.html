USONIAN FRETBOARD GENERATOR v3.0

Creates a continuous fretboard outline and single-line fret slots for Easel.

Recommended Easel workflow: import the fret-slots SVG first, then import the outline SVG separately. This prevents Easel from splitting the continuous side outline at every fret intersection.
The outline file contains one continuous closed path. Every fret in the slots file is one open line. The combined file is provided for convenience, but the two-file workflow is safer in Easel.
